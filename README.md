# Учебный файловый менеджер

Практическое занятие 5 по дисциплине «Сетевые системы и приложения».
Файловый менеджер работает только внутри рабочей папки и не позволяет выйти за её пределы.

## Запуск

Нужен Python 3.9+, сторонние библиотеки не требуются (для псевдографического режима в Windows: `pip install windows-curses`).

```
python3 main.py            # командный режим
python3 main.py --tui      # псевдографический режим (две панели)
python3 main.py --settings другой_файл.json
python3 -m unittest -v     # тесты
```

## Настройки

Файл `settings.json`:

| Параметр     | Назначение                                                     |
|--------------|----------------------------------------------------------------|
| `workspace`  | рабочая папка менеджера (может быть где угодно, `~` допускается) |
| `users_file` | файл учётных записей (относительно рабочей папки)              |
| `quota_mb`   | квота на пользователя в МБ, 0 — без ограничения                |
| `encoding`   | кодировка текстовых файлов                                     |

## Пользователи

При первом запуске пользователь регистрируется; для него создаётся домашняя папка
`<workspace>/home/<имя>`, которая для него является корнем `/`. Пароли хранятся
в виде соли и хеша PBKDF2-HMAC-SHA256.

## Команды

| Команда                     | Действие                               |
|-----------------------------|----------------------------------------|
| `dnew <папка>`              | создать папку                          |
| `ddel <папка>`              | удалить папку                          |
| `dgo <папка>` / `dup`       | войти в папку / подняться вверх        |
| `dlist [папка]`, `here`     | содержимое папки, текущая папка        |
| `fnew <файл>`               | создать пустой файл                    |
| `fwrite <файл> <текст>`     | записать текст (`\n` — перевод строки) |
| `fadd <файл> <текст>`       | дописать текст                         |
| `fshow <файл>`              | показать текстовый файл                |
| `fdel <файл>`               | удалить файл                           |
| `fcopy <файл> <папка>`      | копировать файл                        |
| `fmove <файл> <папка>`      | переместить файл                       |
| `fren <файл> <новое_имя>`   | переименовать файл                     |
| `fpack <объект> <архив>`    | упаковать файл или папку в zip         |
| `funpack <архив> [папка]`   | распаковать zip                        |
| `quota`                     | занятое и свободное место              |
| `help`, `quit`              | справка, выход                         |

Имена с пробелами берутся в кавычки: `fnew "мой файл.txt"`.

## Структура проекта

```
main.py                  точка входа, вход/регистрация, выбор интерфейса
settings.json            настройки
filemanager/config.py    чтение настроек
filemanager/sandbox.py   ограничение путей рабочей папкой
filemanager/operations.py операции с файлами и папками, архивы, квота
filemanager/users.py     регистрация и вход пользователей
filemanager/cli.py       командный интерфейс
filemanager/tui.py       псевдографический интерфейс (curses)
tests/                   модульные тесты
```
